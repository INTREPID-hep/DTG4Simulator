# DTG4Simulator

This code provides a simple DT chambers simulation to study pattern recognition algorithms.

## Particles and physics processes
En esta simulación se usa como "Physics List" [FTFP_BERT](https://geant4-userdoc.web.cern.ch/UsersGuides/AllGuides/html/PhysicsListGuide/reference_PL/FTFP_BERT.html?highlight=ftfp_bert) para simular la interacción de partículas con el material.
